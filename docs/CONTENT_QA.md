# 内容质量与审核

## 状态职责

- `draft`：原创内容编辑中的草稿。
- `pending_review`：已导入或待人工复核；所有商业和第三方内容从此状态开始。
- `reviewed`：人工已完成当前版本的内容复核，但仍不等于已发布。
- `disputed`：答案、题干、来源或重复关系存在争议。
- `published`：由后续专门的发布流程产生。本阶段 Admin 没有批量发布动作。
- `obsolete`：内容不再适用于当前考试版本，但保留历史引用。

已发布版本不可原地修改。修改必须新增版本、重新审核，再由后续发布流程切换；历史版本以及被其他记录引用的数据使用 `PROTECT`。

## 自动检查

导入前至少检查：Schema、题型与答案数量、答案标签存在性、选项标签唯一性、来源页码、置信度、公开边界和稳定外部 ID。重复规则只产生候选，不自动合并。低于 0.8 的提取置信度产生明确警告。

自动检查不能证明答案正确。尤其是相同题干答案不同、相同外部 ID 内容变化、选项顺序变化和来源答案异常，必须保留原始表示并交由人工处理。

## 人工复核清单

1. 核对题干、题型、选项文本和选项顺序。
2. 核对来源答案，不根据程序推测擅自修改。
3. 检查解析是否与答案及适用考试版本一致。
4. 检查章节、知识点、年份和来源页码。
5. 处理低置信度、答案冲突和重复候选警告。
6. 确认来源权利范围和公开许可。
7. 将无法裁定的内容标记为 `disputed`，记录复核依据。

Admin 支持按章节、题型、审核状态、警告、来源文件、提取置信度、答案冲突和重复候选筛选，并可批量标记 `reviewed`、`disputed` 或退回 `pending_review`。任何批量动作都不能直接发布。

## 发布门槛

“成功提取”不等于“答案已复核”，“已复核”也不等于“允许公开”。发布流程必须另行验证版本不可变性、审核记录、来源权利和内容发布范围；该流程不属于本 PR。
