# 内容来源与权利边界

## 允许进入公开仓库的内容

- JSON Schema、导入和审核程序、迁移、测试与文档；
- 为测试专门创作的少量原创演示记录；
- 不含题干、选项和商业原文的聚合校验数字。

公开演示数据必须标记为原创且允许公开。模拟题只能标记为模拟或原创内容，不能冒充历年真题。

## 禁止进入公开仓库的内容

- 商业 PDF、讲义、题库原文、完整提取结果和扫描件；
- `section_questions_raw.jsonl`、真实导入预览、私有报告及其压缩包；
- 私人磁盘绝对路径、下载地址、访问凭据和密钥；
- 可供公众还原或批量获取完整商业题库的数据。

仓库根目录的 `.gitignore`、`.dockerignore` 和 `scripts/check-secrets.sh` 共同拦截 `private-data/`、`source-materials/`、`extracted-content/`、`import-reports/private/`、私有 JSONL、PDF 和 ZIP。Git 忽略不代表可以随意复制：资料应优先保留在仓库外，构建上下文也不得包含它们。

## 私人使用规则

商业资料仅限获得资料的用户私人学习，不向公开 GitHub 提交原文，也不通过产品向公众开放完整商业题库。`SourceMaterial` 只保存最少的来源元数据和逻辑引用，不保存商业文件本体、公开下载地址或本地绝对路径。

`rights_scope=private_personal_use` 必须同时满足 `public_repo_allowed=false`。任何来源权利不明的内容都按更严格边界处理，并保留人工复核记录。

## 来源忠实性

系统保存来源答案，但不自动裁定机构答案冲突，也不自行“纠正”答案。疑似错误、低置信度、重复和冲突必须进入 `warnings` 或 `disputed` 状态，由人工结合合法来源复核。成功提取只说明结构化处理完成，不代表答案正确、权利允许发布或内容已经审核。
