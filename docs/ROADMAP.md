# 实施路线图

## Phase 1：基础骨架

- 架构、数据、内容、安全、API 与 ADR 文档。
- Django 自定义用户、Session 登录、CSRF、Admin 与健康检查。
- React 登录页、受保护仪表盘、TanStack Query、移动端壳与 PWA。
- 开发/生产 Compose、Caddy、Gunicorn、PostgreSQL 和备份恢复脚本。
- 后端格式/测试、前端类型/构建与敏感文件 CI。
- 竞品拆解、信息架构、UX/响应式/设计系统与页面流程文档。
- 手机 8 页、电脑 4 页中保真审核原型；界面确认前不开发业务页面。

## Phase 2：内容管理

- 科目、章节、小节、课程、课时和有序内容块模型。
- 知识点、标签、前置关系和版本审核流。
- Django Admin 内容录入体验和少量原创演示数据。
- Markdown 清洗与 KaTeX 渲染链路。

## Phase 3：基础刷题闭环

- 单选、多选、判断题模型和版本管理。
- 练习会话、答题记录、收藏、错题本与基础统计。
- 先完成单选题端到端，再扩展其他客观题。

## Phase 4：复习与笔记

- 背诵卡版本、复习队列、复习历史和知识掌握度。
- 个人笔记和内容批注。
- 可解释的间隔复习策略。

## Phase 5：案例与模拟考试

- 案例背景、分问、评分点、参考步骤和分问作答界面。
- 模拟试卷、交卷、成绩和分知识点统计。
- 人工复核与争议题处理流程。

## Phase 6：生产强化

- 域名、HTTPS、ICP 备案后的正式入口。
- 恢复演练、监控告警、限流和管理入口强化。
- 性能压测、可访问性审计和内容运营工具。
