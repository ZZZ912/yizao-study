# 响应式设计

## 布局区间

| 区间 | 宽度 | 主要形态 |
| --- | --- | --- |
| Compact | 320–599px | 单列、底部五导航、底部抽屉 |
| Medium | 600–1023px | 单列或主次双列、可收起侧栏 |
| Desktop compact | 1024–1199px | 固定侧栏；目录＋正文两栏；辅助内容进入抽屉 |
| Desktop expanded | 1200–1439px | 固定侧栏；右侧辅助栏可收起 |
| Wide | ≥1440px | 最大内容宽度 1440px，增加留白而非无限拉伸 |

断点由内容需要决定，不以具体设备型号为依据。页面在 200% 缩放与横屏下仍应可操作。

课程型页面在 `<1024px` 保持正文单列，目录与笔记进入抽屉；四档规则先由无业务数据的基础布局和浏览器测试锁定，后续业务页面必须复用同一规则。

## 同一业务，不同布局

| 页面 | 手机 | 电脑 |
| --- | --- | --- |
| 首页 | 今天的任务纵向排列，主任务占首屏 | 左侧导航；中间今日任务；右侧本周节奏和继续学习 |
| 章节 | 章级折叠列表；统计压缩为短标签 | 章节树与详情双栏，可快速比较各章状态 |
| 课程 | 内容单列；目录从底部抽屉打开 | 左目录、中正文、右笔记/目标三栏 |
| 刷题 | 一题一屏，题卡和设置收入抽屉 | 题卡侧栏、题目主区、草稿/知识锚点辅助栏 |
| 解析 | 关键解析优先，完整步骤折叠 | 答案、步骤和知识点可并列，仍保持单一“下一题”主动作 |
| 复习 | 一张卡片一屏，评价按钮置底 | 队列、卡片和复习说明并列 |
| 错题本 | 推荐分组优先，筛选为抽屉 | 筛选侧栏与结果列表并列 |
| 报告 | 先建议后数据，图表一次只显示一个 | 建议、趋势和章节证据同屏但不做数据墙 |

## 手机首屏预算

以 390×844px 为基准：

- 顶部上下文：64px 左右。
- 今日主任务：260–320px。
- 次任务预览：120–180px。
- 底部导航：72–80px，兼容安全区。

首屏不展示大图表、广告、横幅轮播、资讯或超过三个任务。滚动后才出现本周计划和更多入口。

## 尺寸与触控

- 页面水平安全边距：手机 16px，平板 24px，桌面 32px。
- 正文最大行宽：中文 36–42 个汉字；长解析不横跨整个桌面。
- 主按钮手机端在可用时贴近底部操作区，最小高度 48px。
- 选项、章节行和复习评价最小触控高度 48px。
- 任何横向滚动都必须是明确的卡片轨道或表格，不允许正文意外溢出。

## 导航适配

### 手机底部导航

- 始终只有：首页、学习、刷题、复习、我的。
- 标签始终可见，不使用纯图标猜测。
- 答题和课程沉浸页可暂时隐藏底栏，用明确返回路径替代。

### 电脑侧栏

- 240px 展开、72px 收起。
- 导航与内容区滚动相互独立。
- 当前科目和版本显示在导航上方，但切换器不抢占主任务。

## 响应式内容优先级

缩小屏幕时按以下顺序降级：

1. 隐藏辅助说明和低优先级统计。
2. 将筛选、目录、题卡移入抽屉。
3. 将并排模块改为顺序模块。
4. 将表格改为带标签的卡片行。
5. 保留主任务、当前状态、主要动作和退出路径。

绝不通过缩小字号、压窄触控区或仅保留图标来维持桌面布局。

## 响应式验收矩阵

- 360×800：小屏 Android。
- 390×844：手机基准原型。
- 768×1024：平板竖屏。
- 1024×768：小型电脑/平板横屏。
- 1440×1024：桌面基准原型。
- 1920×1080：宽屏留白与最大宽度。
- 浏览器 200% 缩放、键盘导航、减少动态效果模式。
