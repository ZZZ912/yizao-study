# 一造学伴产品需求

## 产品定位

一造学伴面向一级造价工程师备考用户，提供章节培训、知识点学习、记忆复习、智能刷题、错题诊断、案例训练和模拟考试能力。

## 用户角色

- 学员：学习已发布内容并管理自己的学习记录。
- 内容编辑：创建课程、知识点、题目和背诵卡草稿。
- 审核人员：审核内容版本并决定发布、退回或标记争议。
- 管理员：通过 Django Admin 创建用户、分配权限并维护系统配置。

第一阶段关闭公众注册。用户只能由管理员创建；邀请注册仅作为后续扩展点，不提供可调用接口。

## 第一阶段目标

第一阶段只交付可持续开发与安全部署的基础骨架：

1. 可审阅的产品、架构、数据、安全和内容模型文档。
2. 使用自定义用户模型的 Django 项目。
3. Session Cookie 登录、注销、当前用户与 CSRF 接口。
4. Django Admin、存活检查和就绪检查。
5. React 登录页、受保护的空白仪表盘、移动端基础布局和 PWA 壳。
6. 开发与生产容器配置、Caddy 静态文件和 API 入口。
7. PostgreSQL 持久化、备份、校验、保留与恢复脚本。
8. 后端测试、格式检查、前端类型检查和构建 CI。

## 第一阶段非目标

- 不实现公众注册、邀请注册或找回密码。
- 不实现课程编辑器、刷题、错题本、复习算法或考试页面。
- 不批量生成题库、课程正文或案例数据。
- 不引入 Redis、Celery、Elasticsearch、Kubernetes 或对象存储。
- 不在本阶段部署到腾讯云服务器。

## 第一阶段验收标准

- 管理员能够通过管理命令创建超级用户，并通过 Django Admin 创建普通用户。
- 已创建用户可以登录、读取当前登录状态、注销；匿名用户不能访问仪表盘 API。
- 没有公众注册路由。
- `/api/health/live/` 能反映应用进程状态，`/api/health/ready/` 能验证数据库连接。
- React 能完成 CSRF 初始化、登录状态读取、登录和注销。
- 生产环境只由 Caddy 暴露 80/443；数据库和 Gunicorn 没有宿主机端口映射。
- 前端构建产物由 Caddy 提供，不运行长期 Node 服务。
- CI 能阻止格式、测试、类型检查、构建和敏感文件检查失败的变更。
