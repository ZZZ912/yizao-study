# 教育类产品竞品拆解

## 研究范围与方法

本次拆解只研究公开可访问的产品介绍、题库页面、帮助中心和应用商店说明，关注任务结构、信息组织与学习反馈，不采集或复刻页面视觉。访问日期为 2026-08-03。

分析结论分为两层：

- **公开事实**：来源页面明确展示或描述的能力。
- **设计推论**：基于事实推导出的产品机会，不代表竞品内部实现。

本项目不得复制竞品的页面结构、配色、图标、插图、组件细节、营销话术或题目内容。原型中的名称、文案、布局和视觉令牌均为一造学伴独立设计。

## 233 网校：覆盖完整的题库任务入口

### 公开事实

- 公开题库页同时提供章节练习、每日一练、历年真题、模拟试题、易错题等入口。
- “我的记录”聚合做题记录、评估报告、错题、题库笔记和收藏。
- 产品介绍强调章节巩固、真题节奏、每日习惯、错题归纳和能力评估。
- 部分练习完成后会呈现正确率、错题类型等结果信息。

来源：

- [233 网校在线题库](https://ks.233.com/)
- [233 网校题库产品介绍](https://v.233.com/tiku/home/xuanchuan)
- [章节练习、每日练习与结果报告说明](https://www.233.com/jzs1/xinde/202403/13143737145783.html)

### 值得吸收的机制

- 用“练习目的”而非题型名称组织入口：巩固、保持手感、模拟、查漏。
- 将错题、笔记、收藏视为用户持续积累的学习资产。
- 每次练习结束都有明确反馈，不让一次答题成为孤立事件。

### 不采用的做法

- 不把所有练习类型、会员权益、活动和内容推广同时放在首页。
- 不使用网校门户式密集导航，也不设置课程销售横幅和资讯流。
- 不把题量、答题次数或排名当作首页的主要激励。

## 环球网校：教材同步与章节进度

### 公开事实

- 快题库公开说明包含章节练习、每日一练以及测验、学练、背题等模式。
- 题目与知识点关联，错题自动归集并支持重做。
- 官方题库介绍以章节、模拟、真题为主要内容结构，并提供试卷统计。
- 学习产品支持回到上次学习位置，体现课程连续性。

来源：

- [环球网校快题库 App Store 页面](https://apps.apple.com/us/app/%E7%8E%AF%E7%90%83%E7%BD%91%E6%A0%A1%E5%BF%AB%E9%A2%98%E5%BA%93/id1603213853)
- [环球网校智能题库介绍](https://www.hqwx.com/subject/tkztpc/)
- [环球网校帮助中心：题库练习](https://www.hqwx.com/help/)

### 值得吸收的机制

- 科目、教材/考试版本和章节层级必须清楚，避免用户在错误版本中学习。
- 章节列表同时显示题量、已做、错题和学习状态，帮助判断下一步。
- “继续上次学习”比重新寻找课程更符合成人碎片化学习场景。

### 不采用的做法

- 不把学练、背题、测验等模式全部作为一级入口；高级模式在任务设置中展开。
- 不用单纯的已做题量代替掌握度，避免形成虚假的完成感。
- 不让教材目录与练习目录成为两套互不关联的树。

## 粉笔：训练、诊断与复盘闭环

### 公开事实

- 公开内容强调专项练习、智能组卷、模考、错题归集与分层难度。
- 模考具有报名、考试、报告、往期报告和试卷再练等连续环节。
- 官方资料强调基于作答数据进行分数预测、个性化学习任务和模考成绩跟踪。
- 公开备考说明将训练组织为诊断、修正、再验证的循环。

来源：

- [粉笔产品介绍](https://www.fenbi.com/page/qiyejieshao)
- [粉笔模考大赛问答](https://www.fenbi.com/page/mokaodasai-qa)
- [粉笔题库与在线刷题入口](https://www.fenbi.com/b/)
- [专项、错题与模考闭环说明](https://www.fenbi.com/page/information-hub-detail/12)

### 值得吸收的机制

- 专项训练解决单一能力问题，阶段测试验证综合表现，两者目的不同。
- 报告必须给出可执行的下一步，而不只是分数、排名和图表。
- 错因比“对/错”更接近学习干预：概念不清、审题偏差、计算失误、步骤缺失、时间不足。
- 模考结束后应自动进入复盘和再练，而不是停在成绩页。

### 不采用的做法

- 不把排行榜和规模数据作为核心动机，一造学习周期长，更需要稳定节奏。
- 不在手机首页放置大面积能力雷达图、趋势图和排名卡。
- 不允许“智能推荐”成为不可解释的黑盒；推荐必须显示依据和可调整范围。

## 一造学伴的独立产品机会

传统题库擅长“给用户更多题”，一造学伴应回答“此刻学什么、为什么错、下一次如何避免”。核心闭环为：

```text
学习课程 → 理解知识点 → 即时练习 → 标注错因
    ↑                                 ↓
学习建议 ← 阶段测试 ← 间隔记忆 ← 错题复习
```

差异化落点：

1. 章节课程由导学、讲解、公式、例题、工程案例、易错提示和课中练习等有序内容块组成。
2. 每个知识点同时连接课程、题目、错因、背诵卡和阶段测试结果。
3. 首页不是功能大厅，而是学习调度器；用户可以在两次点击内开始当前最重要任务。
4. 报告默认输出一条主建议及证据，高级统计按需展开。
5. 案例题预留分问、评分点和参考步骤，未来报告可以定位“步骤型失分”。

## 防复制检查清单

- 未使用竞品截图作为视觉参考底稿。
- 未采集竞品色值、图标、插画、组件尺寸或营销文案。
- 原型不出现竞品品牌、会员、广告、资讯和课程销售模块。
- 导航、内容层级和关键文案由一造学伴学习闭环重新推导。
- 上线前进行相似性复核；任何明显接近单一竞品的页面都必须重新设计。
